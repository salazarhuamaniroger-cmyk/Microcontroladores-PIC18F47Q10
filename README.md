# Documentación: Práctica de la Semana 2

## Resumen del Proyecto
El archivo **`semana_2.ZIP`** contiene todos los recursos necesarios para el proyecto de la implementación de tres compuertas lógicas NOT.

## Contenido de `semana_2.ZIP`
Al extraer el archivo comprimido, encontrarás los siguientes directorios y archivos principales:

1. **Proyecto Completo en MPLAB X IDE:**
   - Contiene el código fuente, las configuraciones del entorno y los archivos generados para la programación del microcontrolador PIC. 
   - Diseñado para implementar la lógica de tres compuertas NOT.

2. **Simulación en Proteus 8.17:**
   - Archivo de diseño de circuito y simulación (`.pdsprj`).
- Incluye el esquemático completo y las conexiones necesarias para probar el funcionamiento del código en el microcontrolador de forma virtual.

## Requisitos del Sistema
Para abrir y ejecutar correctamente el contenido del proyecto, necesitas:
- **MPLAB X IDE** instalado (junto con el compilador correspondiente, p. ej., XC8 o PIC-AS).
- **Proteus Design Suite 8.17** (o una versión compatible superior).

## Instrucciones de Uso
1. Descomprime el archivo `semana_2.ZIP` en un directorio de tu preferencia.
2. Abre **MPLAB X IDE**, selecciona *Open Project* y carga el proyecto extraído.
3. Compila el proyecto en MPLAB X para asegurarte de que el archivo `.hex` se genere correctamente.
4. Abre el archivo de simulación en **Proteus 8.17**.
5. Haz doble clic sobre el microcontrolador en el esquemático de Proteus y asegúrate de cargar la ruta del archivo `.hex` generado.
6. Inicia la simulación en Proteus para verificar el funcionamiento de las tres compuertas NOT.
